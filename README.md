# To-Do-List
This is a simple game.

A clean, modern, single-file To-Do List app — HTML, CSS and JavaScript all live in `index.html`, so you can deploy it anywhere (GitHub Pages, Netlify, Vercel, or just open the file).

## Features
- Add, edit (double-click), complete and delete tasks — with undo
- Priority levels and due dates (with "Today" and overdue highlighting)
- Filter by All / Active / Completed, plus instant search
- Drag-and-drop reordering
- Progress ring and live stats
- Light and dark themes (remembers your choice)
- Smooth animations, confetti when everything's done
- Tasks saved in your browser (localStorage)
- Keyboard shortcuts: `N` new task, `/` search
- Fully responsive and respects reduced-motion settings

## Deploy on GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
